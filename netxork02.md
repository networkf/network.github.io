<b><font size="5">Netxork v0.2: Agents, Echoes & Network+</font></b>
<br>
<br>
<small>February 2026</small>
<br>
<br>

This was the biggest jump so far: the code nearly doubled. It adds AI agents you can chat with (starting with "Numi"), shown under "Artificial Insights", and replies arrive in real time. People can connect through Echo handshakes, and Node conversations now sit in a Mailbox. Users get public profiles, a Network+ subscription tier, a daily Spark card, and a way to send feedback.

<b>Key features</b>
<br>

- Agents: real-time chat with AI agents (for example Numi)
- Echoes: request and accept connections with other users
- Mailbox for conversations. Nodes now lock after 24 hours instead of 42
- Public profiles that you can edit and view, plus user search
- Network+ subscription page with "Neural Synthesis" perks and a member badge
- Daily Spark card pinned to the home view (text, image or video)
- Edit a feed post within 1 hour, a 280-character limit on fragments, search across fragments
- Feedback form and a new icon navigation bar
