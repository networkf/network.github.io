<b><font size="5">Netxork v0.3: Read Receipts & Public/Private Fragments</font></b>
<br>
<br>
<small>March 2026</small>
<br>
<br>

This update refines the app rather than adding a new area. Fragments can be switched in both directions: "Send to Network" publishes one and "Make Private" takes it back. The Mailbox now tracks read receipts and unread messages, and the app has proper URL routes such as /mailbox.

<b>Key features</b>
<br>

- Send to Network / Make Private controls on fragments
- Read receipts and unread state for Node conversations
- URL slugs for the main sections (for example /mailbox)
- "All Messages" view and a direct Message action
